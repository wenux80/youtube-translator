# YouTube Translate & Speak (AI 优化版)

一款仿制并深度升级的 YouTube 实时双语字幕翻译与语音朗读 Chrome 浏览器插件（Manifest V3）。

本项目针对原插件的核心痛点，重点实现了 **4 大核心优化**：

---

## 🌟 4 大核心优化功能

### 1. AI 翻译分批/指定预处理条数 (避免全量 Token 消耗与超时)
- **痛点**：原插件或同类工具在调用大模型（OpenAI / DeepSeek 等）时往往一股脑将整部视频（数千条字幕）全量发送，不仅极其消耗 Token 费用，而且容易遭遇 API 速率限制（429 Too Many Requests）或请求超时。
- **优化方案**：
  - 支持在设置中自由指定**预处理条数**（如单批 5 ~ 10 条）。
  - 采用**滑动窗口按需预翻译（Lookahead Window）**机制：只在视频即将播放到相应段落前，自动向后预处理指定批次的字幕。
  - 用户也可以在右侧字幕抽屉中点击 **[⚡ 预翻译下 N 条]** 按钮手动批量推进。

### 2. 支持单句重新翻译 (Re-translate Single Sentence)
- **痛点**：当某一句机器翻译不通顺或理解有偏差时，无法单独修正。
- **优化方案**：
  - **播放器悬浮框**：鼠标悬停在当前字幕上时，右上角浮现 **[🔄 重译]** 按钮。
  - **右侧字幕列表**：每一行字幕都有独立的 **[🔄 重译这句]** 按钮。
  - **上下文感知翻译**：重译时会自动将前后相邻的句子作为上下文输入给大模型，大幅提升单句语义准确度，并立即更新画面与本地缓存！

### 3. 支持自由调节字体大小与样式
- **痛点**：视频画面繁杂或屏幕分辨率不同（如 4K 屏 / 笔记本小屏），固定大小的字幕容易遮挡画面或看不清。
- **优化方案**：
  - **播放器快捷键**：播放器右上角悬浮栏内置 **A- / A+** 快捷缩放按钮，一键即时放大缩小。
  - **双语独立字号调节**：支持在 Popup 和设置页中独立调节原文字号（10~36px）和译文字号（14~50px）。
  - **字幕框自由拖拽**：鼠标按住字幕框即可随意拖动到屏幕任意位置（顶部、底部或避开视频原嵌入字幕处），拖拽位置自动保持。
  - 支持文字颜色、描边阴影与背景透明度调节。

### 4. 翻译内容本地持久化缓存（优先命中缓存，0 延时 & 0 额外 Token）
- **痛点**：同一视频反复观看或快进倒退时重复调用 API，白白浪费额度。
- **优化方案**：
  - 基于浏览器的 **IndexedDB** 数据库建立高性能本地存储库。
  - 首次打开视频时**优先检索本地缓存**，若已存在直接毫秒级秒开渲染，完全不消耗任何 API。
  - 当视频播放过程中预处理翻译或单句重译时，自动同步增量写入本地缓存。
  - 在设置页中提供完整的**本地缓存管理面板**：可查看所有已缓存的视频列表、译文条数、一键导出双语 SRT 或清理缓存。

### 5. 点击字幕即时跳转播放 (Seek to Video Timestamp)
- **侧边栏全局点击跳转**：在右侧字幕列表中，点击**任意一句字幕的任何位置**，视频立即平滑跳转到该句对应的时间戳并自动播放。
- **悬浮跳转提示**：鼠标移到字幕卡片上时会自动浮现 `▶ 点击跳转播放` 提示。
- **关键词搜索跳转**：字幕抽屉顶部内置搜索栏，输入中英文关键词即可实时筛选，点击匹配的搜索结果秒达视频对应画面。
- **画面字幕快速重听**：在播放器画面上的双语字幕悬停栏内置 **[⏮️ 句首]** 快捷按钮，或者直接单击画面字幕浮层，即可瞬间返回当前句子开头重听。

## 🚀 基础功能完整复现

1. **多翻译引擎自由切换**：
   - **Google 翻译 (免 Key)**：开箱即用，无需任何配置与 API Key。
   - **DeepSeek AI**：高性价比与顶级翻译能力（支持 `deepseek-chat` / `deepseek-reasoner`）。
   - **OpenAI (ChatGPT)**：支持 `gpt-4o-mini`、`gpt-4o` 等。
   - **Google Gemini**：支持 `gemini-1.5-flash`。
   - **Ollama 本地大模型**：支持本地运行大模型（`http://localhost:11434`），数据 100% 本地隐私。
   - **自定义 API**：兼容任何 OpenAI 规范的第三方转发代理（如 SiliconFlow、Groq、OneAPI 等）。
2. **TTS 智能配音与语音朗读**：
   - 支持浏览器原生 Web Speech 语音库。
   - **原片声音自动避让（Audio Ducking）**：当配音朗读开始时，自动调低 YouTube 原片音量（如降至 30%），朗读完毕淡入恢复。
   - 可调语速（0.5x ~ 2.0x）、音量。
3. **沉浸式右侧字幕抽屉 (Transcript Drawer)**：
   - 点击播放器浮标上的 **[📜 字幕列表]** 展开抽屉。
   - 实时时间戳、播放进度条（已翻译比例）。
   - 点击任意一句时间戳，视频自动跳转播放。
   - 当前正在播放的句子自动高亮并平滑滚动跟随。
4. **双语 SRT 字幕导出**：
   - 随时一键导出当前视频的已翻译双语 SRT 文件。

## 📦 如何安装到 Chrome 浏览器

1. 打开 Google Chrome 或 Edge 浏览器。
2. 在地址栏输入：`chrome://extensions/` 并回车。
3. 在右上角开启 **“开发者模式” (Developer mode)** 开关。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
5. 选择本项目所在目录：
   ```
   D:\DevelopmentKit\Workspaces\node_workspace\youtube-translator
   ```
6. 安装完成后，打开任意一个带字幕的 [YouTube 视频](https://www.youtube.com)，即可在播放器右上角看到控制栏与双语字幕！
